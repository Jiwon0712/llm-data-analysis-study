1. 프로젝트 주제: 한국어 일본 여행 브이로그의 조회수 관련 요인 분석: 제목·영상 길이·업로드 시점·썸네일 문구를 중심으로

2. 해결하고 싶은 문제

관심 현상
- 한국어로 제작된 일본 여행 브이로그는 유튜브에서 인기 있는 콘텐츠이지만, 같은 주제의 영상이어도 조회수는 수백 회에서 수백만 회까지 크게 차이 난다. 이 조회수 차이가 어떤 요소와 관련되어 있는지 알아보고자 한다.

분석 이유
- 크리에이터는 제목, 영상 길이, 업로드 시점, 썸네일 등을 직접 선택할 수 있지만, 그 선택이 조회수와 어떤 관계인지는 경험과 감에 의존하는 경우가 많다. 크리에이터가 조절할 수 있는 요소들과 조회수 사이의 관계를 살펴보고, 이 요소들을 변수로 하여 영상 업로드 전에 조회수를 예측할 수 있을지 분석한다.

활용 대상
- 일본 여행 브이로그를 업로드하려는 크리에이터가 제목, 영상 길이, 업로드 시점을 정할 때 참고하는 자료

한계
- 분석 범위가 일본 여행 브이로그로 한정되어 있어 다른 유튜브 컨텐츠에 적용하기는 어렵다. 썸네일의 문구 포함 여부 외에도 조회수에 큰 영향을 미치는 요소들이 많지만, 변수로 설정하기에는 한계가 있어 제외하였다. 

3. 핵심 분석 질문
Q1. 일본 여행 브이로그의 조회수는 여행지 종류, 업로드 요일, 업로드 시간대에 따라 어떻게 다른가?
Q2. 채널 구독자 수와 업로드 후 경과 일수를 통제한 뒤에도, 제목 길이·영상 길이·썸네일 문구 유무는 조회수와 관계가 있는가?
Q3. 업로드 전에 알 수 있는 정보(제목 길이, 여행지 종류, 영상 길이, 업로드 요일·시간대, 썸네일 문구 유무, 구독자 수)만으로 조회수 상위권 영상을 얼마나 구분할 수 있는가?

변수 구성
종속변수:	조회수 (분석 시 log 변환)
관심변수:	제목 길이, 여행지 종류, 영상 길이, 업로드 요일, 업로드 시간대, 썸네일 문구 유무
통제변수:	채널 구독자 수 (log), 업로드 후 경과 일수

4. 데이터 확보 계획

데이터 출처
YouTube Data API v3 (Google 공식 API)

접근 방법
https://developers.google.com/youtube/v3

수집 방법
- search.list로 검색어 8개("일본 여행 브이로그", "도쿄 브이로그", "오사카 브이로그", "교토 여행 브이로그", "후쿠오카 브이로그", "일본 혼자 여행", "일본 자유여행 브이로그", "일본 소도시 여행")를 검색하여 영상 ID를 수집한다. 조건은 영상 유형 video, 지역 KR, 관련 언어 ko, 검색어당 2페이지(최대 100건)로 한다.
- 검색어 간 중복 영상은 영상 ID 기준으로 제거한다.
- videos.list로 영상별 제목, 업로드 시각, 영상 길이, 조회수, 채널 ID, 썸네일 URL을 가져온다.
- channels.list로 채널별 구독자 수를 가져온다.
- 수집일을 함께 기록한다(경과 일수 계산용). 
- 영상 길이 3분 미만(숏폼), 수집일 기준 업로드 후 2년이 지난 영상, 업로드 후 7일 미만 영상은 제외한다.
- 일본 거주자의 일상 영상, 광고, 일본 여행과 무관한 영상은 제목·채널 정보를 확인하여 제거한다. 판단이 불확실한 영상은 포함한다.

예상 규모
- 수집 후보 영상: 661건 → 숏폼 제외 후 485건(384개 채널)
- 최종 분석 대상: 약 400건 내외 예상

주요 컬럼
video_id	영상 고유 번호
title	영상 제목
published_at	업로드 시각 (UTC)
duration	영상 길이 (ISO 8601, 예: PT12M34S)
view_count	조회수
channel_id	채널 고유 번호
subscriber_count	채널 구독자 수
thumbnail_url	썸네일 이미지 주소
collected_at	데이터 수집일
title_length	제목 글자 수
destination	여행지 종류 (도쿄/오사카/교토/후쿠오카/기타)
duration_min	영상 길이(분)
upload_weekday	업로드 요일 (KST 기준)
upload_timeslot	업로드 시간대 (KST 기준 구간)
days_since_upload	업로드 후 경과 일수 (수집일 − 업로드일)
has_thumbnail_text	썸네일 문구 유무 (1: 있음, 0: 없음)

실제 확보 가능 여부
- 검색어 8개 × 2페이지(검색 16회)로 고유 영상 661건을 확보하였다.
- 숏폼(3분 미만) 제외 후 485건(384개 채널)에서 조회수와 구독자 수를 모두 확인하였다(구독자 수 비공개 채널 없음).
- 수집된 485건 중 최근 2년 이내 영상은 448건이며, 업로드 후 7일 미만 46건을 제외하면 402건이다. 무작위 50건 확인 결과 일본 여행 브이로그로 명확히 판단되는 비율이 약 88% 이상이었으므로, 최종 분석 대상은 약 350건 내외로 예상한다. 표본이 부족할 경우 검색어와 검색 페이지를 추가하여 보완한다.
- 수집에 사용한 할당량은 약 1,700유닛으로 일일 한도(10,000유닛) 내에서 수행되었다. search.list는 호출당 100유닛이 소모되므로, 추가 수집이 필요하면 며칠에 나누어 진행한다.
- 세 분석 질문에 필요한 변수(조회수, 제목, 업로드 시각, 영상 길이, 구독자 수, 썸네일)가 모두 확보되어 있어 Q1~Q3에 답할 수 있다.

한계와 대응
- 검색 결과의 노출 순서가 인기 영상에 치우칠 수 있다. 검색어를 다양화하였으며, 결과 해석 시 한계로 명시한다.
- 384개 채널에서 485건이 수집되어 같은 채널의 영상이 여러 개 포함된다. 채널당 영상 수 분포를 확인하고, 특정 채널의 비중이 크면 채널당 영상 수를 제한하는 방안을 검토한다.
- 검색 결과가 최근 업로드 영상에 치우쳐 있어 경과 일수가 짧은 영상의 비중이 크다. 경과 일수를 통제 변수로 포함하고 업로드 후 7일 미만 영상을 제외하여 영향을 완화하되, 결과는 최근 영상에 한해 해석한다.
- 거주자 영상 제외와 여행지 분류, 썸네일 문구 판단은 연구자의 판단이 개입하므로 기준을 문서로 남기고, 썸네일 라벨링은 일부를 재라벨링하여 일치율을 기록한다.
- 썸네일 이미지 파일은 저장·재배포하지 않고 라벨링 결과(0/1)만 저장한다.

준수 사항
- YouTube API 서비스 약관과 개발자 정책을 따른다. 개인 식별 정보(댓글 작성자 등)는 수집하지 않으며, 수집 데이터는 학습 목적의 분석에만 사용한다. 원본 데이터를 GitHub에 공개해도 되는지 약관을 확인하고, 불가하면 가공한 변수 데이터만 올린다.

5. 예상 분석 방법
- 전처리 단계: 결측/중복/이상값 확인, 영상 길이/업로드 시각 등은 자료형으로 변환, 파생 변수 생성, 조회수/구독자 수 로그 변환
- Q1 분석: 여행지/요일/시간대별 조회수 비교(박스플롯, 중앙값), 비모수 검정
- Q2 분석: 구독자 수와 경과 일수를 통제한 단계별 다중회귀
- Q3 분석: 조회수 상위 25%에 속하는지 여부를 로지스틱 회귀로 분류. 필요시에는 Random Forest 비교.
- 검증: 회귀 진단(잔차, 다중공선성), 학습/테스트 분리와 교차검증, 썸네일 라벨 재확인
  
6. 생성형 AI 활용 계획
- 생성형 AI(Claude)를 프로젝트 전 과정에서 보조 도구로 활용한다. AI가 생성한 코드와 해석은 그대로 사용하지 않고, 실제 데이터와 실행 결과를 기준으로 직접 검증한다.
- 기획 단계: 분석 질문와 변수 설계 검토 시 사용. 실제로 수집 가능한 컬럼과 대조해보고 범위와 변수는 직접 결정할 예정.
- 데이터 수집 단계: API 호출 코드 초안, 할당량 계산. 테스트 호출 결과는 직접 확인.
- 전처리 단계: 시간 변환, 제목 글자 수, 여행지 분류 등의 코드 작성. 분류 결과 일부는 수작업으로 확인하고 검증한다.
- EDA/시각화: 그래프 코드 작성.
- 분석 방법 검토 단계: 검정/모델 선택 근거 및 코드 작성.

사용한 프롬프트와 수정 내용은 기록 예정. AI가 작성한 코드는 최대한 이해한 후 사용 예정.

7. 향후 프로젝트 계획

현재까지 진행한 내용
현재 YouTube Data API 테스트 수집을 마쳤고, 이후 단계는 다음과 같이 진행한다.

2차 (10월 말): 정해진 조건으로 본 수집을 하고 데이터의 구조와 품질을 확인한다. 이후 조건에 맞는 영상만 남겨 전처리하고 파생 변수를 만든다. 썸네일을 직접 보고 문구가 있는지 기록하는 작업도 이때 한다. 마지막으로 여행지, 요일, 시간대별 조회수를 비교하는 탐색적 데이터 분석과 시각화를 수행한다.
3차 (11월 말): 구독자 수와 경과 일수를 통제한 회귀 분석으로 제목 길이, 영상 길이, 썸네일 문구와 조회수의 관계를 확인한다. 업로드 전 정보로 조회수 상위권 영상을 분류하는 모델도 만들고, 학습용과 시험용 데이터를 나누어 성능을 검증한다.
4차 (12월 말): 분석 과정과 결과, 한계, 회고를 최종 보고서로 정리하고 Streamlit으로 핵심 결과를 전달하는 화면을 만든다.

단계별 산출물은 GitHub 저장소의 프로젝트 전용 폴더에서 관리하고, 세부 일정은 학기 일정에 맞추어 조정할 예정이다.
